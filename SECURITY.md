# Security policy

`nirs4all-org` is the static landing page for the nirs4all ecosystem ([nirs4all.org](https://nirs4all.org)):
static HTML/CSS/JS assets with no server-side code, no database, and no user-data collection.

## Reporting a vulnerability

If you find a security issue with the site (e.g. a malicious/hijacked link, an injection vector in embedded
content, or a supply-chain concern in the build), please report it **privately** to
**nirs4all-admin@cirad.fr** rather than opening a public issue.

For a vulnerability in a nirs4all **library**, report it via that project's own `SECURITY.md`.
