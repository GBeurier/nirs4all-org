Migration et support natifs

Contrats, exemples et durée de support proposés pour le candidat R4. Cette page prépare la transition mais ne déclare ni V1 stable, ni disponibilité produit.

Migrer sans modifier la source

Le paquet publié nirs4all-tools 0.0.7 inspecte ou convertit explicitement les stores historiques. La source conserve son chemin, son inode et ses octets; la sortie est un nouveau workspace disjoint. Il n'existe pas de conversion inverse native vers legacy.

python -m venv /opt/nirs4all-tools-0.0.7
/opt/nirs4all-tools-0.0.7/bin/python -m pip install "nirs4all-tools[duckdb,parquet]==0.0.7"
/opt/nirs4all-tools-0.0.7/bin/nirs4all-tools workspace inspect /data/ancien --format text
/opt/nirs4all-tools-0.0.7/bin/nirs4all-tools workspace convert /data/ancien --output /data/native-v2 --verify
/opt/nirs4all-tools-0.0.7/bin/nirs4all-tools legacy verify /data/native-v2 --manifest /data/native-v2/migration-manifest.json

Codes de sortie: 0 conversion complète; 10 sortie sûre avec contenu conservé de façon opaque; 20 refus ou échec. Un code 10 n'est pas une conversion sémantique complète.

Exemple Python natif

import nirs4all

result = nirs4all.run(pipeline="pipeline.yaml", dataset="dataset.yaml")
archive = result.export("./portable-run.n4a")
prediction = nirs4all.predict(model=archive, data="new_dataset.yaml")

rollback = nirs4all.run(

FAQ

Studio doit-il embarquer Python?

Pas comme backend. Un CPython embarqué peut héberger une bibliothèque ou un plugin explicitement choisi, via JSON stdio borné. Le serveur, le store et le scheduler restent Rust.

Studio peut-il revenir automatiquement au backend historique?

Non. Les chemins Studio/Web et les profils Python stricts refusent la capacité indisponible. Le rollback legacy est uniquement un choix visible de l'appelant Python direct.

Un ancien workspace est-il migré à l'ouverture?

Non. La détection est en lecture seule. L'opérateur lance Tools vers une nouvelle destination, puis vérifie le rapport avant basculement.

Cette page annonce-t-elle V1?

Non. C'est une documentation candidate sous hold de publication. Le statut de staging reste l'autorité visible de cette branche.
