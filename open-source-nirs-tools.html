Open-source near-infrared spectroscopy tools

NIRS tools for formats, datasets, methods, pipelines, papers, and browser modelling

nirs4all is an open-source ecosystem for NIR spectroscopy workflows: read vendor files, assemble datasets, run chemometric methods, publish reproducible pipelines, benchmark results, and inspect ecosystem health.
